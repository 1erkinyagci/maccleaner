How to Clear Safari Cache & Website Data on a Mac

MacCleaner · 2026-08-04 · 5 min read

Short answer

To clear Safari's cache on a Mac: Safari → Settings → Advanced → tick Show features for web developers, then use the Develop menu → Empty Caches. To clear website data and cookies: Settings → Privacy → Manage Website Data → Remove All. This fixes glitches and frees space — you'll just re-download assets and sign in again on some sites.

Clear the cache

  1. Safari → Settings → Advanced → enable Show features for web developers.
  2. In the menu bar, Develop → Empty Caches.

That's the cached page assets gone; Safari re-downloads them as you browse.

Clear website data and cookies

  • Safari → Settings → Privacy → Manage Website Data → Remove All (or remove specific sites).
  • This clears cookies and local storage — you'll sign in again on some sites, which is the only real cost.

Frequently asked questions

Is it safe to clear Safari's cache?

Yes. The cache is temporary page assets Safari rebuilds automatically. Clearing website data also removes cookies, so you'll sign in again on some sites — nothing important is lost.

Will clearing Safari cache delete my passwords?

No. Passwords live in your Keychain, not Safari's cache. Clearing website data removes cookies (logins), but saved passwords remain.

How do I free more space beyond Safari?
