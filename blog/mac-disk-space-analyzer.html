The Best Way to See What's Taking Up Space on a Mac (2026)

MacCleaner · 2026-08-04 · 5 min read

Short answer

To see what's taking up space on a Mac, the built-in option is System Settings → General → Storage — but it hides most detail in “System Data.” A disk-space analyzer shows the real breakdown. MacCleaner scans read-only and groups everything by real byte counts and by whether it's safe to remove, so you don't just see where the space went, you see what you can actually reclaim.

Why the built-in Storage screen isn't enough

Apple's Storage screen sorts files into friendly buckets, then dumps everything it can't categorise into “System Data” — often 50 GB+ of caches, snapshots and developer junk with no breakdown. You can see the problem but not act on it.

What a real analyzer shows

A disk-space analyzer measures the actual bytes on disk and maps them, so a mystery 60 GB becomes a list of folders you can act on. The best ones also tell you what's safe — because a cache and an irreplaceable file look identical in a raw map. See finding large files for the manual methods.

Frequently asked questions

How do I see what's taking up space on my Mac?

System Settings → General → Storage gives a rough breakdown, but hides most of it in System Data. A disk-space analyzer that measures real bytes shows the true detail.

What is the best free disk space analyzer for Mac?

Options range from the built-in Storage screen to third-party tools. MacCleaner scans free and, unlike a plain map, labels what's safe to remove versus what's personal.

Why doesn't macOS show what's in System Data?

Apple's Storage screen only categorises files it recognises; the rest — caches, snapshots, developer artifacts — all land in System Data with no breakdown.
