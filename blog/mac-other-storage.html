What Is “Other” Storage on a Mac — and How to Clear It

MacCleaner · 2026-08-04 · 6 min read

Short answer

“Other” storage is the old name for what macOS now calls System Data: caches, logs, APFS snapshots, disk images, fonts, plugins and developer build artifacts — everything that doesn't fit Apps, Photos or Documents. It can top 50GB. The safely clearable parts are app caches, logs and developer artifacts — not the system itself.

“Other” is now “System Data”

Older macOS versions labelled this bucket “Other”; newer ones call it System Data. Same thing: the catch-all for files macOS can't sort into Apps, Photos or Documents. If you're looking for “Other,” you want the System Data guide — this is the short version.

What's actually inside

ComponentReclaimable?
App caches & logsYes — safely
APFS / Time Machine snapshotsManaged by macOS
Developer build artifactsYes — rebuildable
Disk images, fonts, pluginsReview individually
System filesNo

How to clear the safe parts

  • App caches and logs — instant, safe.
  • Developer artifacts — Xcode, node_modules, Docker.
  • Leave snapshots to macOS.

Frequently asked questions

What is “Other” storage on a Mac?

It's the older name for System Data — caches, logs, snapshots, disk images, fonts, plugins and developer artifacts that don't fit Apps, Photos or Documents. It can exceed 50GB.

How do I clear “Other” storage on a Mac?

Clear the safe parts: app caches, logs and developer build artifacts. Leave snapshots and system files to macOS. Don't delete things you can't identify.

Why is “Other”/System Data so large?

Usually caches plus APFS/Time Machine snapshots, and on developer Macs, Xcode DerivedData and other build artifacts.
